# Logo sources

Every logo here is a trademark of its owner, shown only to identify the service CreMore connects to
or finds a credential for. `web/console/logo-set.ts` lists the brand files by the id the API uses.

| Files | Source | Terms |
| --- | --- | --- |
| `github.svg`, `gitlab.svg`, `bitbucket.svg`, `confluence.svg`, `aws.png`, `s3.svg`, `awssm.svg`, `gcp.png`, `gcs.png`, `notion.png` | The console design mockup (each brand's published logo) | Brand guidelines of each owner |
| `azure.svg` (Azure A), `azure_devops.svg`, `azure_key_vault.svg` | Microsoft Azure public service icons V22 (`arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V22.zip`) | Microsoft Terms of Use shipped with the icon set |
| `entra_id.svg` | Microsoft Entra architecture icons, Oct 2023 (`download.microsoft.com`, "Microsoft Entra ID color icon") | Microsoft Terms of Use shipped with the icon set |
| `slack.svg` | Slack's own site mark (`a.slack-edge.com/.../marketing/img/nav/logo.svg`) | Slack brand guidelines |
| `keycloak.svg` | Keycloak's own site icon (`www.keycloak.org/resources/images/icon.svg`) | Linux Foundation trademark usage |
| `google_workspace.png` | The Google "G" that workspace.google.com declares as its own icon, 128 px (`www.gstatic.com/images/branding/googleg_gradient/1x/googleg_gradient_standard_128dp.png`, 2026-09-30); Google publishes no square Workspace mark, only the wordmark | Google brand guidelines |
| Every other `.svg` | Simple Icons 16.33.0 (`cdn.jsdelivr.net/npm/simple-icons@16.33.0/icons/<slug>.svg`), filled with the brand colour Simple Icons records; a light brand colour becomes the tile with the mark dark on it | CC0-1.0, except the files below |
